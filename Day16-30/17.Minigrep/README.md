# Day 17 - 命令行程序实例 (minigrep)

这是一个经典的 Rust 入门项目：构建一个简化版的 `grep` 命令行工具。
它接受两个参数：文件名和要搜索的字符串。

## 1. 关注点分离
我们将程序逻辑拆分为 `src/main.rs` 和 `src/lib.rs`。
- `main.rs`: 负责解析参数、调用库函数、处理错误。
- `lib.rs`: 包含配置结构体、业务逻辑和测试。

## 2. 接收命令行参数
使用 `std::env::args()`。

## 3. 文件读取
使用 `std::fs`。

## 4. 环境变量
使用 `std::env::var()` 来检查环境变量（例如 `CASE_INSENSITIVE`）。

## 5. 错误处理
使用 `Result` 和 `Box<dyn Error>` 来统一处理不同类型的错误。

## 6. 测试驱动开发 (TDD)
我们先写一个失败的测试，然后实现功能让它通过。
